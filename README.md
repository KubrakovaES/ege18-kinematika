# Верно или неверно? Кинематика

Тренажёр к заданию №18 ЕГЭ по физике. Ученик видит утверждение и выбирает «Верно» или «Неверно». Карточка переворачивается и показывает правильный ответ с объяснением. Утверждения идут вперемешку, ошибки собираются справа и повторяются, пока не будут решены верно.
